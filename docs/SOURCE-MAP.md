# Included implementation and public adaptations

[The machine-readable source map](source-map.json) identifies each reviewed source input, its hash and the public file. The project includes selected implementation, not private Git history or a complete business application.

| Area | Treatment |
| --- | --- |
| Import cycle, journal and timing | Copied selected implementation and three original test files. |
| Production Dockerfile and smoke | Unchanged references; the full production browser/MFA dependency set is not supplied here. |
| Root Dockerfile | Same base and runtime pattern; fictional default command and a smaller synthetic browser check. |
| Package files | Existing dependency resolutions retained; only the root name and example commands change. |
| Deployment checks | Four original pure functions retained without the Azure adapter or live CLI; same digest-format rule supplied separately. |
| ARM job | Actual structure with fictional names, identities, endpoints, owner and accepted digest. |
| Terraform network module | Related original reusable module kept as reference. |
| Terraform example job | New teaching code, default Off and Manual; not the production job owner. |
| Viewer, local demos and selection tests | New public teaching code using fictional inputs and the included original rules. |

Before copying the source subset, an in-memory payload review checked the generated bytes for organization/resource identifiers, credential patterns, personal email addresses and nonpublic dependency-download hosts. A hash-bound copy was permitted after that review. A separate final publishable-tree scan and link check are recorded in validation.

The Docker base digest is real and public. Example image digests, identity values and resource addresses are fictional and cannot authorize a deployment. No employee data, provider secrets, saved browser state or signing key is included.
